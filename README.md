# 小黑盒网页社区优化

用于小黑盒网页社区的 Tampermonkey 用户脚本，当前版本为 2.4.2。

主要功能：隐藏左右侧栏、压缩帖子间距、标题单行省略、正文最多显示两行，以及限制图片显示数量，提高一屏可浏览的帖子数量。

社区首页的搜索栏、社区图标和帖子列表整体居中，最大宽度为 1280px；窗口较窄时随窗口收缩。帖子详情页与评论也使用居中的内容列。

帖子正文使用 24px 字号和 1.7 倍行距，覆盖 ArticleKit 文章、引用、列表、旧版编辑器和图文帖正文。

## 使用方法

1. 在浏览器中安装 Tampermonkey 扩展。
2. 点击 [安装或更新脚本](https://raw.githubusercontent.com/admin05/xiaoheihe/main/xiaoheihe.user.js)，在 Tampermonkey 页面中确认安装或更新。
3. 若旧版是手动复制安装的，也需要通过上述链接更新一次，以写入更新地址。若安装后出现两个同名脚本，禁用或删除旧版，只保留新版。
4. 打开或刷新小黑盒网页，脚本会自动生效。

## 自动更新

脚本头部已配置 `@updateURL` 和 `@downloadURL`，均指向 GitHub `main` 分支上的 `xiaoheihe.user.js`。仓库需保持公开，以便 Tampermonkey 无需 GitHub 登录即可获取脚本。

- 在 Tampermonkey 管理面板的设置中启用脚本更新检查，并按需设置检查间隔（例如每天）。如果看不到相关设置，可切换到高级配置模式。
- 需要立即更新时，在管理面板中对本脚本执行“检查更新”。具体按钮名称可能随扩展版本和语言变化。
- 发布新版本时，修改 `xiaoheihe.user.js`，递增头部的 `@version`，再提交并推送到 `main`。仅推送代码而不提高版本号，不会触发正常的版本更新。
- 保持脚本的 `@name`、`@namespace` 和更新地址稳定，便于后续覆盖更新。

如果点击安装链接只显示源码，可在 Tampermonkey 中新建脚本，复制完整源码并保存；更新地址会随脚本一同保存。

该脚本在浏览器中运行，依赖页面 DOM 和 MutationObserver。

## 语法检查

安装 Node.js 后运行：

```sh
node --check xiaoheihe.user.js
```
