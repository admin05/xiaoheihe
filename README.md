# 小黑盒网页社区优化

用于小黑盒网页社区的 Tampermonkey 用户脚本，当前版本为 2.1。

主要功能：隐藏左右侧栏、压缩帖子间距、标题单行省略、正文最多显示两行，以及限制图片显示数量，提高一屏可浏览的帖子数量。

## 使用方法

1. 在浏览器中安装 Tampermonkey 扩展。
2. 新建用户脚本，将 `小黑盒网页社区优化 - 高信息密度版-2.1.txt` 的完整内容复制到编辑器并保存。
3. 打开或刷新小黑盒网页，脚本会自动生效。

该脚本在浏览器中运行，依赖页面 DOM 和 MutationObserver。

## 语法检查

安装 Node.js 后运行：

```sh
node --check < '小黑盒网页社区优化 - 高信息密度版-2.1.txt'
```
